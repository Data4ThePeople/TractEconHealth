# TractEconHealth

A Data 4 The People project comparing the economic health of U.S. census tracts with measures of physical and mental health.

This project is in early exploration. There is no post or published visualization yet.

## What will be here

- Scripts that pull tract-level economic measures from the Census Bureau's American Community Survey (2020-2024 5-year estimates).
- Scripts that pull tract-level health estimates from CDC PLACES, and county-level death data from CDC WONDER.
- `DATASETS.md`: what each source is, its limits, and how we handle them.
- `dist/`: the built interactive visualization, once it exists.

## Data sources

- U.S. Census Bureau, American Community Survey 5-year estimates
- CDC PLACES: Local Data for Better Health
- CDC WONDER mortality data
